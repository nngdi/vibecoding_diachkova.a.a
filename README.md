# Vibe Coding for Business — Дьячкова Ангелина

Репозиторий содержит лабораторные работы по курсу **Vibe Coding for Business**.

Проект представляет собой Telegram-бота **«Учебный планировщик»**, который развивается от лабораторной к лабораторной: от базового функционала до подключения базы данных и облачного развертывания.

---

## Структура проекта

- `lab_1` — первая лабораторная работа: создание Telegram-бота
- `lab_2` — вторая лабораторная работа: подключение SQLite
- `bot.py` — актуальная версия Telegram-бота
- `requirements.txt` — зависимости проекта
- `.env.example` — пример переменных окружения
- `.gitignore` — исключаемые из GitHub файлы
- `Procfile` — команда запуска бота в Railway
- `report_lab3.md` — отчёт по лабораторной работе №3

---

## Лабораторная работа №1

### Telegram-бот «Учебный планировщик»

В первой лабораторной работе был разработан Telegram-бот для организации учебных задач и расписания.

Основные функции:

- добавление учебных задач;
- выбор даты и времени;
- выбор приоритета задачи;
- просмотр задач на сегодня;
- просмотр плана на ближайшие 7 дней;
- добавление учебных занятий;
- выбор типа занятия: лекция или практика;
- хранение университетского расписания;
- отображение времени начала и окончания занятий;
- перевод московского времени в пекинское;
- выполнение и удаление задач;
- работа через кнопки Telegram.

---

## Лабораторная работа №2

Во второй лабораторной работе функциональность Telegram-бота была расширена.

Для хранения данных подключена база данных **SQLite**.

Добавлены:

- постоянное хранение задач;
- постоянное хранение учебного расписания;
- добавление, чтение, изменение и удаление данных;
- статистика по задачам;
- история выполненных задач;
- обработка ошибок при работе с базой данных.

Бот продолжает поддерживать отображение московского и пекинского времени.

---

## Лабораторная работа №3

В третьей лабораторной работе бот был подготовлен к реальному использованию и развернут в облачной среде.

Для деплоя использован **Railway**.

Выполнено:

- подготовка проекта к облачному развертыванию;
- хранение Telegram-токена через переменные окружения;
- настройка `.gitignore`;
- настройка `requirements.txt`;
- добавление логирования;
- настройка `Procfile`;
- развертывание Telegram-бота на Railway;
- использование Python 3.11;
- подключение Railway Volume;
- постоянное хранение базы данных SQLite после перезапуска сервиса;
- проверка работы бота после деплоя.

Пользовательское тестирование и улучшения по обратной связи будут добавлены после завершения тестирования.
