# Промпты для LLM

## Исходный промпт
Создай Telegram-бота на Python с использованием библиотеки python-telegram-bot. Бот-ассистент для задач: принимает задачи, организует по приоритетам, отправляет напоминания и формирует списки дел. Код должен быть простым, понятным и с обработкой ошибок.

## Итерация 1
Добавь даты и время дедлайнов, три уровня важности, просмотр задач на сегодня и неделю, расписание университета и напоминания о занятиях.

## Итерация 2
Переделай интерфейс на кнопочный: главное меню, кнопки выбора даты, времени, приоритета, дня недели, а также кнопки «Выполнено» и «Удалить».

## Финальный промпт
Создай Telegram-бота — учебный планировщик на Python с использованием python-telegram-bot. Бот должен работать через кнопки, хранить задачи с датой, временем и приоритетом, показывать план на сегодня и неделю, хранить расписание занятий, напоминать о дедлайнах и за 30 минут до занятий, сохранять данные в JSON и безопасно получать BOT_TOKEN из переменной окружения.
