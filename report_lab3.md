# Лабораторная работа №3
## Развертывание и тестирование Telegram-бота

### 1. Цель работы

Цель лабораторной работы — развернуть Telegram-бота в облачной среде, обеспечить его постоянную работу, провести пользовательское тестирование и улучшить приложение на основе обратной связи.

---

### 2. Описание проекта

Проект представляет собой Telegram-бота-планировщика для управления учебными задачами и расписанием.

Основные функции бота:

- добавление задач;
- выбор приоритета задачи;
- указание даты и времени;
- просмотр задач на сегодня;
- просмотр плана на неделю;
- добавление учебных занятий;
- выбор типа занятия: лекция или практика;
- просмотр расписания;
- перевод времени из московского часового пояса в пекинский;
- статистика;
- история выполненных задач;
- хранение данных в SQLite.

---

### 3. Подготовка к развертыванию

Для подготовки проекта к развертыванию были настроены следующие файлы:

- `requirements.txt` — содержит зависимости проекта;
- `.env.example` — пример переменной окружения для Telegram-токена;
- `.gitignore` — исключает секретные и временные файлы;
- `Procfile` — содержит команду запуска приложения;
- `bot.py` — основной файл Telegram-бота.

Токен Telegram-бота не хранится в открытом виде в GitHub. Он передается через переменную окружения `BOT_TOKEN`.

---

### 4. Развертывание

Для развертывания был выбран облачный сервис Railway.

Репозиторий проекта был подключен к Railway через GitHub.

В Railway были настроены переменные окружения:

`BOT_TOKEN` — токен Telegram-бота.

Для совместимости используемых библиотек была задана версия Python 3.11.

Также был подключен Railway Volume для постоянного хранения SQLite-базы данных.

База данных сохраняется в подключенном хранилище и не удаляется после перезапуска приложения.

---

### 5. Проверка работы после развертывания

После развертывания бот был протестирован непосредственно в Telegram.

Проверены следующие функции:

- запуск команды `/start`;
- добавление задачи;
- выбор даты и времени;
- выбор приоритета;
- просмотр списка активных задач;
- отметка задачи как выполненной;
- добавление занятия;
- просмотр расписания;
- просмотр задач на сегодня;
- просмотр плана на неделю;
- статистика;
- история выполненных задач.

Бот работает независимо от локального компьютера и продолжает отвечать пользователям после развертывания в Railway.

---

### 6. Возникшие проблемы

Во время развертывания возникло несколько технических проблем.

Первая проблема была связана с установкой лишних зависимостей в `requirements.txt`. После удаления неиспользуемых библиотек развертывание прошло успешно.

После подключения постоянного хранилища потребовалось повторно настроить переменную окружения `BOT_TOKEN`.

Также Railway по умолчанию использовал Python 3.13, который оказался несовместим с используемой версией `python-telegram-bot`. Для решения проблемы была установлена версия Python 3.11.

После внесения изменений бот успешно запустился.
