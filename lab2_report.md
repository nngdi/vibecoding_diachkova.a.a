## 2. Выбранный источник данных

В качестве источника данных была выбрана база данных SQLite.

SQLite используется для хранения:

- учебных задач;
- даты и времени дедлайна;
- приоритета;
- статуса выполнения;
- расписания занятий;
- типа занятия;
- времени начала и окончания.

---

## 3. Почему выбран SQLite

SQLite подходит для небольшого учебного проекта, так как:

- не требует отдельного сервера;
- входит в стандартную библиотеку Python;
- позволяет работать с SQL-запросами;
- удобно хранит структурированные данные;
- поддерживает добавление, чтение, изменение и удаление записей.

По сравнению с JSON база данных удобнее для поиска, фильтрации и получения статистики.

---

## 4. Структура данных

Используются две таблицы.

### Таблица tasks

Хранит информацию о задачах:

- `id` — уникальный ID;
- `user_id` — Telegram ID пользователя;
- `text` — название задачи;
- `due_datetime` — дата и время дедлайна;
- `priority` — приоритет;
- `done` — статус выполнения;
- `created_at` — дата создания;
- `completed_at` — дата выполнения.

### Таблица lessons

Хранит расписание занятий:

- `id` — ID занятия;
- `user_id` — Telegram ID;
- `name` — название предмета;
- `lesson_type` — лекция или практика;
- `weekday` — день недели;
- `start_time` — начало занятия;
- `end_time` — окончание занятия;
- `created_at` — дата создания записи.
