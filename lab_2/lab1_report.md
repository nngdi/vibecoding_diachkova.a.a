# Лабораторная работа №1
## Создание Telegram-бота с помощью LLM

## 1. Описание задачи
Создан Telegram-бот — учебный планировщик. Он хранит задачи и дедлайны, учитывает важность, ведёт расписание занятий и отправляет напоминания.

## 2. Проблема
Во время обучения одновременно возникает много лабораторных, домашних заданий, презентаций и занятий. Бот объединяет задачи, сроки, приоритеты и расписание в одном интерфейсе Telegram.

## 3. Почему выбрана эта задача
Telegram используется ежедневно, поэтому планировщик внутри мессенджера удобнее отдельного приложения и хорошо демонстрирует возможности Telegram Bot API.

## 4. Промпты
Исходный и улучшенные промпты находятся в [`prompts.md`](prompts.md). Первая версия была простым списком задач, затем были добавлены даты, приоритеты, расписание, напоминания и кнопочный интерфейс.

## 5. Функционал
Главное меню:
- ➕ Добавить задачу
- 📅 Сегодня
- 🗓 Неделя
- 📚 Расписание
- 📋 Все задачи
- ➕ Добавить занятие

При создании задачи пользователь вводит только название, затем выбирает дату, время и уровень важности кнопками.

## 6. Стек технологий
| Технология | Назначение |
|---|---|
| Python | основной язык |
| python-telegram-bot | Telegram Bot API |
| JSON | хранение задач и расписания |

| ChatGPT | генерация и улучшение кода |

## 8. Трудности и решения
На Windows команда Python в PowerShell не распознавалась, поэтому для запуска был выбран Google Colab. Первая версия требовала много текстовых команд, поэтому интерфейс был переработан на кнопки.

## 9. Ограничения
При запуске через Google Colab бот работает только пока активна среда выполнения. Для постоянной работы его можно разместить на сервере.
