# Study Planner Bot — Lab2

Во второй лабораторной работе учебный Telegram-бот подключён к базе данных **SQLite**.

## Что добавлено в Lab2

Вместо JSON используется файл:

`planner.db`

Новые возможности:

- сохранение задач в SQLite;
- сохранение расписания в SQLite;
- получение активных задач из базы;
- обновление статуса задачи;
- удаление задач и занятий;
- `📊 Статистика`;
- `🕘 История` выполненных задач;
- обработка ошибок базы данных.

Существующий функционал Lab1 сохранён.

## Таблицы

### tasks

Хранит:

- текст задачи;
- дату и время;
- приоритет;
- статус;
- дату создания;
- дату выполнения.

### lessons

Хранит:

- название дисциплины;
- лекцию или практику;
- день недели;
- время начала;
- время окончания.

## Главное меню

```text
➕ Добавить задачу      📅 Сегодня
🗓 Неделя               📚 Расписание
📋 Все задачи           ➕ Добавить занятие
📊 Статистика           🕘 История
```

## Требования

- Python 3.10+
- `python-telegram-bot[job-queue]`
- `nest_asyncio`

Для SQLite используется стандартный модуль Python `sqlite3`.

## Безопасность

Настоящий токен не хранится в исходном коде.  
Для демонстрации базы в репозитории следует использовать только тестовые данные.
