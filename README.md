# Vibe Coding — Дьячкова Ангелина

Репозиторий для лабораторных работ по курсу **Vibe Coding for Business**.

## Структура

- `lab1` — Telegram-бот «Учебный планировщик»
- `lab2` — подключение учебного планировщика к базе данных SQLite

## Lab1

В первой лабораторной работе был создан Telegram-бот, который:

- позволяет добавлять учебные задачи;
- сохраняет дату, время и приоритет;
- показывает задачи на сегодня и ближайшие 7 дней;
- хранит университетское расписание;
- различает лекции и практики;
- показывает время начала и окончания занятий;
- переводит московское время в пекинское;
- отправляет напоминания;
- позволяет выполнять и удалять задачи.

Отчёт находится в:

`lab1/report/report.md`

## Lab2

Во второй лабораторной работе бот был подключён к базе данных **SQLite**.

Добавлено:

- хранение задач и расписания в SQLite вместо JSON;
- операции добавления, чтения, изменения и удаления данных;
- `📊 Статистика`;
- `🕘 История` выполненных задач;
- обработка ошибок при работе с базой.

Отчёт находится в:

`lab2/report/report.md`
