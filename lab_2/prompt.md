# Prompt — Lab2

Улучши существующего Telegram-бота — учебный планировщик на Python.

Сохрани функционал первой лабораторной:

- кнопочное меню;
- задачи;
- дата, время и приоритет;
- просмотр на сегодня и неделю;
- расписание;
- лекции и практики;
- время начала и окончания;
- перевод Москва → Пекин;
- напоминания;
- выполнение и удаление задач.

Замени хранение данных в JSON на SQLite.

Создай таблицу `tasks`:

- id;
- user_id;
- text;
- due_datetime;
- priority;
- done;
- created_at;
- completed_at.

Создай таблицу `lessons`:

- id;
- user_id;
- name;
- lesson_type;
- weekday;
- start_time;
- end_time;
- created_at.

Реализуй:

- добавление данных;
- чтение данных;
- изменение статуса задачи;
- удаление данных;
- просмотр активных задач;
- просмотр расписания;
- историю выполненных задач;
- статистику.

Добавь кнопки:

- `📊 Статистика`;
- `🕘 История`.

Для статистики показывай количество задач, выполненных и активных задач, задачи высокого приоритета, количество занятий, лекций и практик.

Используй параметризованные SQL-запросы и обработку `sqlite3.Error`.

Telegram Bot Token не должен храниться в коде.

Создай:

1. обновлённый `bot.py`;
2. файл базы данных;
3. обновлённый `README.md`.
