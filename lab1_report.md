# Лабораторная работа №1
## Создание Telegram-бота с помощью LLM

1. Описание задачи
В рамках лабораторной работы был разработан Telegram-бот — учебный планировщик.
Бот позволяет:
- добавлять задачи;
- указывать дату и время выполнения;
- выбирать уровень важности задачи;
- просматривать задачи на сегодня;
- просматривать план на неделю;
- добавлять расписание занятий;
- получать напоминания о занятиях и дедлайнах;
- автоматически переводить московское время в пекинское;
- отмечать задачи выполненными;
- удалять задачи и занятия.
Управление ботом реализовано преимущественно через кнопки Telegram.

2. Какую проблему решает бот
Основная проблема — большое количество учебных задач и занятий, о которых легко забыть.
Особенно часто возникают сложности с расписанием пар. Сейчас я нахожусь в Китае, при этом расписание университета указано по московскому времени. Из-за разницы во времени приходится постоянно самостоятельно пересчитывать время занятий, что может привести к путанице и пропуску пары.
Бот позволяет хранить расписание, задачи и дедлайны в одном месте и автоматически показывает время одновременно по Москве и Пекину.

3. Почему выбрали именно эту задачу
Я выбрала именно учебный планировщик, потому что эта задача связана с моей реальной проблемой.
Я периодически забываю о запланированных делах и особенно о времени занятий. Дополнительную сложность создаёт нахождение в Китае и разница во времени с Москвой.
Поэтому хотелось создать бот, которым можно пользоваться не только для выполнения лабораторной работы, но и в повседневной жизни.

Промпт для LLM
Для создания программы использовалась LLM. Разработка проходила в несколько этапов: от простого бота для хранения задач до учебного планировщика с кнопками, расписанием, напоминаниями и поддержкой двух часовых поясов.

5. Исходный промпт
Создай Telegram-бота на Python с использованием библиотеки
python-telegram-bot.

Бот-ассистент для задач.

Функционал бота:
- принимает задачи в текстовом виде;
- организует их по приоритетам;
- отправляет напоминания;
- формирует списки дел.

Требования:
- бот должен быть простым и понятным;
- код должен быть хорошо прокомментирован;
- использовать файл для хранения данных JSON;
- добавить обработку ошибок.

Создай:
1. bot.py с кодом бота;
2. requirements.txt с зависимостями;
3. README.md с инструкцией по запуску;
4. .env.example для примера конфигурации.

6. Итерации и улучшения
После создания первой версии бот был протестирован и несколько раз доработан.
Первая версия позволяла:
- добавлять задачи;
- выводить список задач;
- отмечать задачи выполненными;
- удалять задачи.

  После тестирования стало понятно, что такой вариант недостаточно удобен для ежедневного использования.
Вторая итерация
Были добавлены:
- дата выполнения задачи;
- время;
- высокий, средний и низкий приоритет;
- просмотр задач на сегодня;
- просмотр задач на неделю;
- расписание занятий.
Третья итерация
Интерфейс был переработан на кнопочный.


При создании задачи пользователь вручную вводит только название, а дату, время и уровень важности выбирает кнопками.

Были добавлены автоматические напоминания:
- о задаче — перед дедлайном;
- о занятии — за 30 минут до начала.
Пятая итерация
Была добавлена поддержка двух часовых поясов.
Все занятия и дедлайны пользователь вводит по московскому времени. Бот автоматически переводит время в пекинское и показывает оба варианта.
Это улучшение было добавлено из-за того, что я нахожусь в Китае, а университетское расписание указано по московскому времени.

7. Финальный промпт
   Создай Telegram-бота — учебный планировщик на Python
с использованием библиотеки python-telegram-bot.

Бот должен работать преимущественно через кнопочный интерфейс.

Необходимо реализовать:

1. Главное меню:
- Добавить задачу
- Сегодня
- Неделя
- Расписание
- Все задачи
- Добавить занятие

2. Добавление задачи:
- пользователь вводит название задачи;
- выбирает дату кнопками;
- выбирает время;
- выбирает уровень важности:
  высокий, средний или низкий.

3. Для каждой задачи хранить:
- название;
- дату;
- время;
- приоритет;
- статус выполнения.

4. Реализовать университетское расписание:
- название дисциплины;
- день недели;
- время начала занятия.

5. Реализовать просмотр:
- задач и занятий на сегодня;
- плана на ближайшие 7 дней;
- полного расписания;
- всех активных задач.

6. Для задач добавить кнопки:
- Выполнено;
- Удалить.

7. Для занятий добавить возможность удаления.

8. Реализовать напоминания:
- перед дедлайном задачи;
- за 30 минут до занятия.

9. Все даты и время пользователь вводит по московскому времени.

10. Бот должен автоматически переводить московское время
в пекинское и показывать оба варианта.

11. При переходе времени через полночь правильно изменять
день и дату для Пекина.

12. Хранить данные в JSON.

13. Telegram Bot Token не должен быть записан непосредственно в коде.

14. Добавить обработку ошибок.

Код должен быть понятным и прокомментированным.

10. Почему выбрали именно их
Библиотека python-telegram-bot была выбрана, потому что она предоставляет готовые инструменты для работы с Telegram Bot API, сообщениями, командами, кнопками и напоминаниями.
datetime необходима для работы с датами и временем.
zoneinfo позволяет корректно работать с часовыми поясами. Благодаря этому не требуется вручную прибавлять определённое количество часов — бот самостоятельно переводит московское время в пекинское.
json был выбран как простой способ хранения информации. Для небольшого учебного проекта полноценная база данных не требуется.
Google Colab был выбран как среда запуска, поскольку при первоначальной попытке запуска Python через Windows PowerShell команда py не распознавалась.

14. Трудности и решения
Во время выполнения лабораторной работы возникло несколько трудностей, связанных с запуском программы, интерфейсом бота, напоминаниями и работой с часовыми поясами, а также общением с ИИ.
15. С какими проблемами столкнулись
Первая проблема возникла при попытке запустить Python на компьютере через Windows PowerShell. Команда py --version не распознавалась системой.
Вторая проблема была связана с интерфейсом первой версии бота. Изначально большинство действий выполнялось с помощью команд /add, /list, /done, /delete. Такой способ оказался неудобным для постоянного использования.
Третья проблема заключалась в том, что простого списка задач оказалось недостаточно. Для полноценного учебного планировщика необходимо было добавить даты, время, уровень важности и расписание занятий.


16. Как их решили
Проблема с запуском Python была решена использованием Google Colab. Это позволило запускать Python-код непосредственно в браузере без дополнительной настройки среды на компьютере.
Для повышения удобства интерфейс был переработан на кнопочный. Пользователь теперь выбирает основные действия с помощью кнопок Telegram.
