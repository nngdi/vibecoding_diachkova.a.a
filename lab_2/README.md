# Lab 2 — Telegram Study Planner + SQLite

Во второй лабораторной работе бот из Lab 1 был расширен интеграцией с базой данных **SQLite**.

## Что изменилось

В Lab 1 данные хранились в JSON.  
В Lab 2 задачи и расписание хранятся в `planner.db`.

Дополнительно добавлены:

- `📊 Статистика`;
- `🕘 История выполненных задач`;
- SQL-запросы для добавления, чтения, обновления и удаления данных;
- обработка ошибок базы данных.

## Структура базы данных

### `tasks`

| Поле | Назначение |
|---|---|
| `id` | ID задачи |
| `user_id` | Telegram ID пользователя |
| `text` | Текст задачи |
| `due_datetime` | Дата и время дедлайна |
| `priority` | Приоритет 1–3 |
| `done` | Статус выполнения |
| `created_at` | Дата создания |
| `completed_at` | Дата выполнения |

### `lessons`

| Поле | Назначение |
|---|---|
| `id` | ID занятия |
| `user_id` | Telegram ID пользователя |
| `name` | Название дисциплины |
| `lesson_type` | `lecture` / `practice` |
| `weekday` | День недели 0–6 |
| `start_time` | Начало занятия |
| `end_time` | Окончание занятия |
| `created_at` | Дата создания записи |

## CRUD

Реализованы:

- **Create** — добавление задач и занятий;
- **Read** — просмотр задач, расписания, статистики и истории;
- **Update** — отметка задачи выполненной;
- **Delete** — удаление задач и занятий.
